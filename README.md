# README — перенос в Claude Code

## Что в этой папке

```
CLAUDE.md          ← Claude Code читает это автоматически при каждом запуске
START-PROMPT.md    ← текст, который ты вставляешь ПЕРВЫМ сообщением в чат
STRATEGIE.md        ← бизнес-стратегия, 90 дней, цены
site-v1/            ← весь текущий сайт (18 страниц) как рабочий черновик
compliance/         ← юридический чек-лист, реестр лицензий, Model-Release
```

## Как перенести

1. Скачай и распакуй эту папку целиком туда, где будет жить проект, например:
   `~/projects/mein-studio/`
2. В терминале: `cd ~/projects/mein-studio` затем `claude`
3. Claude Code запустится и сам подхватит `CLAUDE.md` — весь контекст уже у него.
4. Открой `START-PROMPT.md`, скопируй текст под разделителем целиком, вставь как
   первое сообщение в чат.
5. Дальше — интервью. Отвечай по существу, не торопи «сразу код» — весь смысл
   переноса в том, чтобы в этот раз пройти нормальный процесс, а не получить ещё
   один быстрый черновик.

## Если Claude Code сразу начинает писать код

Значит, он проигнорировал порядок действий — редко, но бывает при длинном контексте.
Останови и напиши прямо: «Сначала интервью по discovery-interviewing, я не просил
код». Он вернётся к CLAUDE.md.

## Про существующие файлы

`site-v1/` — рабочий сайт, а не просто референс: если Claude Code решит, что
структура и юридическая база v1 в целом годные и нужно только докрутить дизайн и
контент, он может редактировать эти файлы прямо на месте, а не создавать всё с нуля.
Если решите вместе перейти на другой стек — старый сайт всё равно останется как
страховка и как источник уже готовых немецких и английских текстов.
