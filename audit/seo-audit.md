# SEO / Подача информации — технический аудит

Проверено вручную (Read/Grep), без агента — механическая проверка по всем 18 страницам
(`site-v1/*.html`, `site-v1/en/*.html`).

---

## Major

**1. `og:image` указывает на несуществующий файл**
Все 18 страниц ссылаются на `{{DOMAIN}}/assets/img/og.jpg` (`og:image`, `twitter:card
summary_large_image`), но `site-v1/assets/img/` пуст. Любой шеринг ссылки — Instagram-био,
WhatsApp, LinkedIn, Facebook — покажет пустую/битую карточку вместо превью.
Это прямо бьёт по стратегии проекта (outbound + Instagram-трафик — сайт как конвертер
для ссылки, отправленной руками). Нужен минимум один og-image (1200×630) до первого
реального использования сайта в переписке.

**2. `index.html` meta description — 209 символов**
Google обычно обрезает сниппет на ~155–160 символах на десктопе. Текущее описание
почти наверняка обрежется посреди слова в выдаче. Файл: `site-v1/index.html:7`.

---

## Minor

**3. `en/index.html` meta description — 164 символа**
Чуть за безопасным пределом, менее критично чем п.2, но стоит подрезать заодно.

**4. Structured data (JSON-LD) — только на главной**
`index.html`/`en/index.html` содержат `ProfessionalService`-схему, остальные 16 страниц —
нет. Не блокер, но `leistungen.html`/`en/services.html` — кандидат на `Service`-схему
(четыре пакета как `hasOfferCatalog`) для более богатых сниппетов в поиске. Можно
отложить, не критично для запуска.

**5. Alt-тексты изображений — сейчас нечего проверять**
На сайте пока 0 (ноль) тегов `<img>` — весь визуал ещё плейсхолдеры (открытый пункт
в CLAUDE.md — реальные фото/видео не выбраны). Как только появятся настоящие фото —
alt-тексты обязательны на каждое (WCAG/BFSG, дублирует пункт в compliance-аудите) —
фиксирую здесь только как "проверить повторно, когда появятся реальные ассеты".

---

## Проверено и в порядке (не требует действий)

- `<title>` на всех 18 страницах — в разумных пределах (18–59 символов), не обрезаются.
- Ровно один `<h1>` на каждой странице.
- `canonical` + `hreflang` (de/en/x-default) — взаимно согласованы, без противоречий,
  проверено на паре DE↔EN страниц (leistungen.html ↔ en/services.html).
- `<html lang="de">` / `<html lang="en">` — корректно расставлены по всем файлам.
- `og:locale` — `de_DE` на немецких, `en_GB` на английских страницах — корректно.
- `robots.txt` + `sitemap.xml` — присутствуют, ссылаются друг на друга, sitemap содержит
  hreflang-альтернативы для каждой пары страниц.
